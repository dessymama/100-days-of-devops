Day 58 – Combining Bash Skills

What I Learned

- Combined variables, user input, functions, loops, and conditions into one Bash script.
- Built a simple server health checker.
- Practiced writing a script that behaves like a small automation tool.

Challenges Encountered

- I initially entered responses after the script had already finished, which caused Bash to treat my answers as commands.

Resolution

- I ran the script again and entered my responses only when the prompts appeared. The script then executed successfully from start to finish.

DevOps Lesson Learned

Real automation scripts are built by combining simple Bash concepts. Writing, testing, fixing mistakes, and documenting the process are all part of becoming a better engineer.
