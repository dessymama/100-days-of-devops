Day 65 – Log File Analyzer

What I Learned

- Learned how to check if a file exists using "-f".
- Counted the number of log entries with "wc -l".
- Displayed the last five log entries using "tail".
- Used "exit 1" to stop the script when an error occurs.

Challenges Encountered

- I had to understand how Bash reads and analyzes log files instead of simply displaying their contents.

Resolution

- I successfully used "wc -l" to count log entries and "tail" to inspect the most recent events, which are common troubleshooting techniques in Linux.

DevOps Lesson Learned

Logs tell the story of what is happening on a server. Being able to quickly locate and analyze recent log entries is an essential troubleshooting skill for every DevOps engineer.
