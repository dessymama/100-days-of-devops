Day 70 – Mini System Monitor

What I Learned

- Combined multiple Linux monitoring commands into a single Bash script.
- Used "df" to monitor disk usage.
- Used "free" to monitor available memory.
- Used "grep -c" to count error entries in a log file.
- Built a system summary using multiple "if" statements.

Challenges Encountered

- I needed to combine several Bash concepts into one script while ensuring each section worked correctly.

Resolution

- I reused the techniques I learned in previous days and organized them into a single monitoring tool that reports disk usage, memory usage, and log errors.

DevOps Lesson Learned

Real-world DevOps scripts often combine multiple system checks into one automated report. Building reusable monitoring tools saves time and helps identify system issues quickly.
