Day 77 – File Cleanup Automation

What I Learned

- Used "touch" to create temporary files.
- Used wildcards ("*.tmp") to work with multiple files at once.
- Used "rm -f" to delete files automatically.
- Verified successful cleanup by checking if any temporary files remained.

Challenges Encountered

- No major challenges. The script successfully created and removed the temporary files.

Resolution

- Confirmed that all ".tmp" files were deleted after the cleanup process.

DevOps Lesson Learned

Automating cleanup tasks helps keep Linux systems organized, reduces unnecessary disk usage, and minimizes manual maintenance.
