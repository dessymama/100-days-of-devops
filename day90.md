Day 90 – System Health Dashboard

What I Learned

- Combined multiple Linux system checks into a single Bash dashboard.
- Displayed hostname, date, CPU load, memory, disk usage, and uptime.
- Used conditional statements to summarize system health.
- Built a simple monitoring dashboard similar to those used by system administrators.

Challenges Encountered

- The root disk usage remained at 100%, so the dashboard correctly reported a critical disk status.

Resolution

- Verified that the dashboard accurately collected system information and generated the expected health summary.

DevOps Lesson Learned

A centralized health dashboard provides a quick overview of system status and helps administrators identify problems faster. Combining multiple monitoring checks into one report is a common DevOps practice.
