Day 56 – Bash Functions

What I Learned

- Created reusable Bash functions.
- Called multiple functions within a script.
- Learned how functions help organize automation scripts.

Challenges Encountered

- I had to remember that defining a function alone does not execute it. Each function must be called explicitly.

Resolution

- After defining each function, I called them in the desired order:
  - "welcome"
  - "server_status"
  - "goodbye"
  - "motivation"

DevOps Lesson Learned

Functions make scripts modular, reusable, and easier to maintain. As automation grows, breaking tasks into functions improves readability and simplifies troubleshooting.
