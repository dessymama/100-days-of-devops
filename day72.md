Day 72 – System Information Report

What I Learned

- Used "hostname" to display the system hostname.
- Used "whoami" to identify the current user.
- Used "date" to display the current date and time.
- Used "pwd" to display the current working directory.
- Used "uname -r" to display the Linux kernel version.
- Practiced command substitution using "$(...)".

Challenges Encountered

- There were no major issues. The script executed successfully and displayed all the required system information.

Resolution

- I verified that each Linux command produced the expected output and combined them into a single system information report.

DevOps Lesson Learned

Gathering system information is one of the first tasks when connecting to a new Linux server. Automating these checks helps engineers quickly understand the environment they are working in.
