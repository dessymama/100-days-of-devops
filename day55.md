Day 55 – Bash Conditions

What I Learned

- Used "if" and "else" statements.
- Took user input using "read".
- Compared user input to make decisions.

Challenges Encountered

- I accidentally named my script "sever-check.sh" instead of "server-check.sh".
- "chmod +x server-check.sh" failed because the filename was incorrect.

Resolution

- Used "ls" to check the files in the directory.
- Renamed the file using:
  "mv sever-check.sh server-check.sh"
- Made the script executable with:
  "chmod +x server-check.sh"

DevOps Lesson Learned

Small mistakes like a typo in a filename can cause commands to fail. Always verify filenames with "ls" before troubleshooting further.
