Day 88 – System Log Backup

What I Learned

- Used "mkdir -p" to create a backup directory.
- Used "cp" to back up a log file.
- Generated timestamped backup filenames using the "date" command.
- Automated a simple log backup process with Bash.

Challenges Encountered

- No major challenges. The backup was created successfully with a unique timestamp.

Resolution

- Verified that the backup file was created in the "log_backups" directory with the correct filename.

DevOps Lesson Learned

Regular log backups are an important part of system administration. Automating backups helps protect important system information and simplifies recovery when needed.
