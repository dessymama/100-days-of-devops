Day 59 – Bash Command-Line Arguments

What I Learned

- Learned how to use command-line arguments ("$1") in Bash scripts.
- Used "-z" to check if an argument was provided.
- Created a reusable function that accepts a service name as input.

Challenges Encountered

- I accidentally mixed example commands into my script, causing unexpected output and Bash errors.

Resolution

- I reviewed the script, removed the extra lines, and kept only the required code. After testing with different arguments, the script worked correctly.

DevOps Lesson Learned

Command-line arguments make scripts reusable and flexible. Instead of editing a script each time, you can pass different values when running it, which is how many real DevOps automation scripts work.
