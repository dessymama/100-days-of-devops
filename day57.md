Day 57 – Bash Loops

What I Learned

- Used a "for" loop to automate repetitive tasks.
- Iterated through a list of server names using a loop variable.
- Learned how loops make Bash scripts shorter and more efficient.

Challenges Encountered

- I initially worked with only three servers, then modified the script to include five servers as part of the challenge.

Resolution

- I updated the list in the "for" loop to include "Mail" and "DNS", then changed the final message to confirm that the health check completed successfully.

DevOps Lesson Learned

Loops are a fundamental automation tool. Instead of repeating the same command multiple times, a single loop can perform the task efficiently for many servers or resources.
