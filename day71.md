Day 71 – Service Status Checker

What I Learned

- Used Bash arrays to store multiple service names.
- Looped through an array using a "for" loop.
- Used logical OR ("||") to check multiple conditions in an "if" statement.
- Built a script that reports the status of several services.

Challenges Encountered

- I learned how arrays make it easier to process multiple values without repeating code.

Resolution

- I used a "for" loop to iterate through the array and applied conditional checks to each service.

DevOps Lesson Learned

Automation becomes more powerful when scripts can process multiple resources efficiently. Arrays and loops help reduce repetitive code and make scripts easier to maintain.
